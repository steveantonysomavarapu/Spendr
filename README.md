# Spendr — Mobile Expense Tracker App

> A production-style expense tracking application built using **React Native** and **Expo**.

## Features
- **Total Balance & Budget Tracking:** Real-time calculation of total expenses and remaining monthly budget.
- **Category Filter Slicer:** Filter transactions by category (Food 🍔, Transport 🚗, Bills ⚡, Shopping 🛍️, Entertainment 🎬).
- **Add Expense Modal:** Form validation to quickly log new transactions.
- **Delete & Manage Transactions:** Delete individual items with dynamic UI updates.
- **Firebase Auth Simulation:** User profile badge integration.

## Tech Stack
- **Framework:** React Native + Expo
- **Language:** JavaScript (ES6+)
- **Styling:** React Native `StyleSheet` with modern dark mode aesthetic

## How to Run Locally

```bash
# Install dependencies
npm install

# Start Expo dev server
npm start
```
